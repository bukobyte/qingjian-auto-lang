---
title: 自动语言
order: 4
description: 为最近使用的应用指定输入语言，切回应用时自动使用对应语言。
---

macOS 支持。青简保持为当前输入法，进入不同应用时自动切换青简内部的输入语言。

## 开启

打开「设置 → 自动语言」，开启「按应用自动切换」。「未设置的应用」决定没有单独规则的应用使用哪种语言，初始为中文。

需先开启「设置 → 中英文 → 中英文切换」。关闭自动语言后，当前输入语言保持不变，仍可手动切换。

## 为应用设置语言

1. 切换到要设置的应用。
2. 打开青简设置的「自动语言」页。
3. 在「刚才使用的应用」右侧下拉框选择输入语言，选择后立即保存。

「添加应用…」只列出最近使用的十个应用，同一应用只出现一次，最近使用的排在最前。点选应用、选择语言后保存。若列表中没有目标应用，先切换到该应用，再返回设置。

当前 macOS 可选中文、英文和越南语输入。下拉框按当前平台实际支持的输入语言提供选项，与候选词的辅助译文语言无关。「跟随默认」使用本页「未设置的应用」所选语言。

已设置的应用可直接在列表中修改或移除。移除规则后，该应用跟随默认语言。最近列表重启后清空，已设置的规则继续保留。

## 手动切换与应用范围

应用内手动切换语言后，本次停留期间保持手动选择。同一应用内换窗口或输入框不会重新应用规则；离开应用后再返回，恢复为该应用设置的语言。

未启用单击 `Shift` 时，`Caps Lock` 仍可手动切换中英文；自动语言使用内部模式，键盘灯位不再代表当前输入语言。关闭自动语言后，本次青简运行期间继续保持这种手动切换方式，当前语言不会突然改变。

规则按应用生效。同一浏览器的不同网页、VS Code 编辑区与其集成终端共用一条规则。切换到其他系统输入法时，自动语言不会切回青简。

## 切换提示

「显示切换提示」默认开启。输入语言实际变化时，屏幕角落短暂显示「已切换到英文输入」等提示，语言没有变化时不重复显示。关闭提示不影响自动切换；「预览提示」只展示效果，不改变输入语言。

最近应用在本机内存中保存，不记录窗口标题或输入内容。应用识别不需要读取其他应用的窗口或光标。
