# 自动语言交互原型

这是用于确认设置体验的临时原型，不接入生产程序。设计见 [auto-language-switch.md](../../../../docs/design/auto-language-switch.md)。

在仓库根目录运行：

```sh
open apps/settings/prototypes/auto-language/recent-apps.prototype.html
```

在聊天内预览中还会显示应用图标。原型只有示例应用和内存状态，刷新后重置，不读取真实应用、不保存青简配置。

主要操作：

- 在“刚才使用的应用”的下拉框选择输入语言，选择即保存；语言选项与其他规则共用。
- “添加应用”仅显示最近十个应用，点选后保存语言；已有规则更新原条目。
- 修改或移除已设置规则，预览完整文字的语言切换提示。
- 设置窗口下方的演示控制可模拟进入应用、手动选择语言；它们不属于正式设置页。

原型的可用语言表模拟当前 macOS 已接入的中文、英文、越南语；正式实现从当前平台输入模式能力读取，不能把辅助译文语言表当成输入模式表。

原型用于验证已经选定的列表形式，不包含搜索、文件选择器、真实系统监听或真实跨进程通信。实际模式兼容与真机首键验证属于后续实现。
